# Stakeholder Memo

**To:** Investment Mentor / Robotics Allocation Team
**From:** Alice
**Re:** Robotics-Sector Portfolio — Problem Framing

## Context
The robotics sector spans ~120 names with uneven analyst coverage, making manual position sizing time-consuming and inconsistent month to month.

## The Problem
We need a repeatable way to turn raw price data into a defensible set of portfolio weights, without relying on ad hoc judgment calls that are hard to audit.

## Why It Matters
Inconsistent sizing either overconcentrates risk in a handful of names or dilutes returns through flat diversification — both hurt risk-adjusted performance.

## What Success Looks Like
A monthly, reproducible weight table with a documented Sharpe ratio and drawdown profile, ready for review before each rebalance.
